# bihter GAMES

Bağımsız oyun stüdyosu resmi sitesi.

## Geliştirme

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
npm run preview
```

Logolar `public/logos/` altında:
- `logo-white.jpg` — beyaz logo (siyah zemin)
- `logo-lime.jpg` — yeşil logo (siyah zemin)
- `logo-on-lime.jpg` — siyah logo (yeşil zemin)
